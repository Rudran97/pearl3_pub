# PWM Module

There are six PWM modules supported by the microcontroller. The period for the PWM is generated by the Dual Compare Timers (DCT).
The timer assigned to each module is as follows:

1. PWM0 uses DCT1A.
2. PWM1 uses DCT1B.
3. PWM2 uses DCT2A.
4. PWM3 uses DCT2B.
5. PWM4 uses DCT3A.
6. PWM5 uses DCT3B.

Each module feature the following characteristics:

* 12-bit resolution.
* Reconfigurable duty cycle.
* The output of the PWM starts as soon as the corresponding timer is started.

The following registers are associated with the PWM module:

**Note**: x = [0:5]

## PWM Control Register (PWMxCON)

| Bit   | Name    | Access | Description                                                                                                |
| :---  | :---    | :---   | :---                                                                                                       |
| 15:12 | PWMxPIN | RW     | PWM pin: `PWM[0:2]` and `PWM[3:5]` can be mapped to any pins of PORTA and PORTB respectively.              |
| 11:0  | PWMxPR  | RW     | PWM period value: This value must be equal to the timer match value used while configuring the DCT module. |

## PWM Duty Cycle Register (PWMxDC)

| Bit   | Name    | Access | Description                                  |
| :---  | :---    | :---   | :---                                         |
| 15:12 | -       | -      | -                                            |
| 11:0  | PWMxDC  | RW     | PWM duty cycle value in range 0 to `PWMxPR`. |
